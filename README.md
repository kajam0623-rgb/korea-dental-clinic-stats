# 전국 치과 현황 통계 (시도·시군구별)

전국 치과의원·치과병원 **19,636곳**을 시도(17곳)와 시군구(255곳)별로 센 공개 통계입니다.
전문의가 있는 치과, 콘빔CT 보유, 평일 야간·토요일·일요일 진료, 최근 1년 새로 문을 연 치과 수를 담았습니다.

- 자료 기준일: 건강보험심사평가원 전국 병의원 현황 **2026-06-30**
- 진료시간 확인: **2026-09-28** (심평원 의료기관별 상세정보, 없으면 국립중앙의료원 병·의원 찾기)
- 만든 곳: [덴탈웹 치과찾기 (dentalweb.co.kr)](https://dentalweb.co.kr/) — 지역별 치과 목록과 치과별 진료시간·전문의·장비는 사이트에서 볼 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `data/시도별.csv` | 17개 시도. 치과 수, 인구 1만 명당 치과 수, 항목별 개수, 전문의 있는 치과 비율 |
| `data/시군구별.csv` | 255개 시군구. 항목별 개수 |
| `data/summary.json` | 전국 합계와 기준일 |

CSV 는 UTF-8(BOM) 이라 엑셀에서 바로 열립니다.

## 전국 합계

| 항목 | 치과 수 | 비율 |
|---|---:|---:|
| 전체 치과 | 19,636 | 100% |
| 그중 치과병원 | 248 | 1.3% |
| 전문의가 있는 치과 | 6,784 | 34.5% |
| 콘빔CT 보유 | 16,661 | 84.8% |
| 평일 20시 이후까지 진료 | 5,761 | 29.3% |
| 토요일 진료 | 17,484 | 89.0% |
| 일요일 진료 | 747 | 3.8% |

비율은 모두 전체 19,636곳을 분모로 한 값입니다.

## 항목 정의

- **전문의가 있는 치과**: 심평원 자료에 과목별 치과 전문의가 1명 이상 신고된 곳. 전문의 여부는 해당 분야 자격을 뜻하며 진료 실력을 뜻하지 않습니다.
- **콘빔CT 보유**: 심평원 장비 현황에 콘빔CT가 1대 이상 신고된 곳.
- **진료시간**: 심평원에 진료시간을 신고한 치과는 그 신고값, 신고가 없으면 국립중앙의료원 자료를 씁니다. 둘 다 없는 411곳은 진료시간 항목에서 빠집니다. 공휴일·점심시간·임시 휴진은 반영하지 않습니다.
- **평일 20시 이후 진료**: 월~금 중 하루라도 마감이 20:00 이후인 곳.
- **최근 1년 개원**: 개설일자가 2025-07-01 이후인 곳.
- **인구**: 행정안전부 주민등록 인구(2026년 8월).
- **지역 이름**: 사이트와 같은 이름을 씁니다(예: 전라북도, 강원도, 제주도).
